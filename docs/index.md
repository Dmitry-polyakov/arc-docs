# 🚀 Работа с Arc: Внесение изменений и создание Pull Request

## Введение
Данная инструкция описывает процесс работы с системой контроля версий Arc. Все команды выполняются в терминале и аналогичны Git, за исключением создания Pull Request.

!!! info "Системные требования"
    - Установленный Arc CLI (версия 2024.1+)
    - Настроенный доступ к репозиторию
    - Права на создание веток и Pull Request
    - Терминал или командная строка

## 📋 Пошаговая инструкция

### 🔄 1. Обновление локальной копии
Перед началом работы синхронизируйте локальный репозиторий:

```bash
	# Переключение на основную ветку
	arc checkout main # (1)

	# Получение последних изменений
	arc pull # (2)
```

1.	!!! annotation "Параметры команды"
	`arc checkout main`: Переключает текущую ветку на main. Убедитесь, что вы находитесь на актуальной ветке перед началом работы.

2.	!!! annotation "Параметры команды"
	`arc pull`: Загружает последние изменения из удаленного репозитория и сливает их с локальной веткой.

<div class="step-card"> Важно: Всегда начинайте с обновления основной ветки, чтобы избежать конфликтов. </div>

### 🌿 2. Создание новой ветки
Создайте ветку для ваших изменений:

```bash
	# Создание ветки
	arc branch feature-branch # (1)

	# Переключение на ветку
	arc checkout feature-branch # (2)
```

1.	!!! annotation "Параметры команды"
	`arc branch feature-branch`: Создает новую ветку с именем feature-branch. Используйте осмысленные имена (например, feat/, fix/).

2.	!!! annotation "Параметры команды"
	`arc checkout feature-branch`: Переключает рабочую область на созданную ветку.

<div class="step-card">
  Рекомендации:<br>
  - Используйте осмысленные имена веток (`feat/`, `fix/`, `docs/`)<br>
  - Избегайте пробелов в названиях<br>
  - Следуйте соглашениям вашей команды
</div>

### ✏️ 3. Внесение изменений
Отредактируйте файлы в вашем редакторе кода. Для проверки изменений:

```bash
	# Просмотр изменённых файлов
	arc status # (1)
```

1.	!!! annotation "Параметры команды"
	`arc status`: Показывает список измененных, новых и удаленных файлов в рабочей директории.

### 💾 4. Сохранение изменений
Зафиксируйте изменения в репозитории:
```bash
	# Добавление всех изменённых файлов
	arc add . # (1)

	# Или конкретных файлов
	arc add file1.js file2.css # (2)

	# Создание коммита
	arc commit -m "feat: добавить новую функциональность

	➤ Реализован компонент X
	➤ Добавлены тесты
	➤ Обновлена документация

	Related: PROJ-123" # (3)
```

1.	!!! annotation "Параметры команды" 
	`arc add .`: Добавляет все измененные файлы в индекс для коммита.

2.	!!! annotation "Параметры команды" 
	`arc add file1.js file2.css`: Добавляет только указанные файлы в индекс.

3.	!!! annotation "Параметры команды" 
	`arc commit -m "..."`: Создает коммит с указанным сообщением. Используйте структурированный формат с точками и ссылками на задачи.

### ☁️ 5. Отправка изменений
Отправьте ветку на удалённый сервер:

```bash
	# Первая отправка ветки
	arc push --set-upstream origin feat/new-feature # (1)

	# Последующие отправки
	arc push # (2)
```

1.	!!! annotation "Параметры команды"
	`arc push --set-upstream origin feat/new-feature`: Отправляет ветку и устанавливает отслеживание удаленного репозитория.

2.	!!! annotation "Параметры команды"
	`arc push`: Отправляет обновления в уже отслеживаемую ветку.

### 🚀 6. Создание Pull Request
Создайте PR для ревью кода:

```bash
	# Базовый PR
	arc pr create -m "Описание изменений" # (1)

	# При необходимости указать ревьюеров
	arc pr create -m "Описание" --reviewers user1,user2 # (2)

	# Создать черновик PR
	arc pr create -m "Описание" --draft # (3)

	# Связать с задачей в трекере
	arc pr create -m "Описание" --task PROJ-123 # (4)
```

1.	!!! annotation "Параметры команды"
	`arc pr create -m "..."`: Создает Pull Request с указанным описанием.

2.	!!! annotation "Параметры команды"
	`arc pr create -m "..." --reviewers user1,user2`: Добавляет указанных ревьюеров к PR.

3.	!!! annotation "Параметры команды"
	`arc pr create -m "..." --draft`: Создает черновик PR для предварительного обсуждения.

4.	!!! annotation "Параметры команды"
	`arc pr create -m "..." --task PROJ-123`: Связывает PR с задачей в трекере.

### 🔧 7. Внесение правок после ревью
Если требуется доработка:

```bash
	# Внесение изменений
	arc add изменённый_файл.js # (1)

	# Обновление коммита
	arc commit --amend # (2)

	# Принудительная отправка
	arc push --force # (3)
```

1.	!!! annotation "Параметры команды"
	`arc add изменённый_файл.js`: Добавляет измененный файл в индекс.

2.	!!! annotation "Параметры команды"
	`arc commit --amend`: Обновляет последний коммит, включая новые изменения.

3.	!!! annotation "Параметры команды"
	`arc push --force`: Принудительно отправляет изменения, перезаписывая удаленную ветку. Используйте с осторожностью!

### ✅ 8. Завершение работы с веткой
После принятия PR и слияния изменений:

```bash
	# Возврат на основную ветку
	arc checkout main # (1)

	# Обновление основной ветки
	arc pull # (2)

	# Удаление локальной ветки
	arc branch -d feat/new-feature # (3)

	# Удаление удалённой ветки (опционально)
	arc push origin --delete feat/new-feature # (4)
```

1.	!!! annotation "Параметры команды"
	`arc checkout main`: Переключает на основную ветку.

2.	!!! annotation "Параметры команды"
	`arc pull`: Синхронизирует основную ветку с удаленным репозиторием.

3.	!!! annotation "Параметры команды"
	`arc branch -d feat/new-feature`: Удаляет локальную ветку после завершения работы.

4.	!!! annotation "Параметры команды"
	`arc push origin --delete feat/new-feature`: Удаляет ветку на удаленном репозитории.

### 🛠 10. Полезные команды

```bash
	# Просмотр истории коммитов:
	arc log # (1)	

	# Сравнение изменений:
	arc diff # (2)

	# Временное сохранение изменений:
	arc stash # (3)

	# Просмотр удаленных веток:
	arc branch -r # (4)

	# Интерактивный rebase:
	arc rebase -i HEAD~3 # (5)

	# Просмотр состояния репозитория:
	arc status # (6)

	# Отмена изменений в файле:
	arc checkout -- файл # (7)
```

1.	!!! annotation "Параметры команды"
	`arc log`: Показывает историю коммитов в текущей ветке.

2.	!!! annotation "Параметры команды"
	`arc diff`: Отображает различия между рабочей директорией и последним коммитом.

3.	!!! annotation "Параметры команды"
	`arc stash`: Сохраняет текущие изменения без коммита.

4.	!!! annotation "Параметры команды"
	`arc branch -r`: Показывает список удаленных веток.

5.	!!! annotation "Параметры команды"
	`arc rebase -i HEAD~3`: Интерактивно переупорядочивает последние 3 коммита.

6.	!!! annotation "Параметры команды"
	`arc status`: Показывает текущее состояние репозитория.

7.	!!! annotation "Параметры команды"
	`arc checkout -- файл`: Отменяет изменения в указанном файле.
